## 실습 파일 준비

실습에 필요한 다음 파일들이 준비되어 있어야 합니다:

- `streamlit_app.py`: 메인 Streamlit 애플리케이션 파일
- `caesar_cipher.py`: 시저 암호 브루트 포스 실습 파일
- `brute_force_analysis.py`: 키스페이스와 브루트 포스 공격 분석 실습 파일
- `frequency_analysis.py`: 빈도 분석 기반 암호 해독 실습 파일
- `requirements.txt`: 필요한 파이썬 패키지 목록

`requirements.txt` 파일에는 다음 내용이 포함되어야 합니다:

```
streamlit 
plotly
pandas
numpy 
```

## 실습 내용

이 실습은 다음과 같은 내용을 포함합니다:

1. **시저 암호 브루트 포스**: 시저 암호화된 텍스트를 무차별 대입 공격으로 해독하는 과정을 학습합니다.
2. **키스페이스 및 브루트포스 분석**: 암호 키스페이스의 크기와 브루트 포스 공격 시간의 관계를 분석합니다.
3. **빈도 분석 기반 암호 해독**: 문자 출현 빈도를 분석하여 단일 치환 암호를 해독하는 기법을 학습합니다.

각 실습은 이론적 배경과 함께 실습 코드 블록을 직접 맞추고 분석하는 형태로 구성되어 있습니다.
